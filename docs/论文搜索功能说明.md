# 学术论文搜索功能 (Academic Paper Search)

## 概述

学术论文搜索功能允许用户通过 API 查询计算机科学领域（特别是安全和软件工程）的学术论文。系统集成了 Semantic Scholar API，并内置了相关领域的高质量论文作为 fallback。

## API 端点

### 搜索论文

**URL**: `POST /api/v1/papers/search`

**请求体**:
```json
{
  "query": "multi-agent secure code generation",
  "limit": 5,
  "venue": "CCS",
  "yearFrom": 2020,
  "yearTo": 2024
}
```

**参数说明**:
- `query` (必需): 搜索关键词或主题
- `limit` (可选): 返回结果数量，默认 5，最大 20
- `venue` (可选): 会议/期刊名称筛选
- `yearFrom` (可选): 起始年份
- `yearTo` (可选): 结束年份

**响应示例**:
```json
{
  "success": true,
  "message": "搜索成功",
  "data": {
    "query": "multi-agent secure code generation",
    "total": 3,
    "source": "semantic_scholar",
    "papers": [
      {
        "paperId": "abc123",
        "title": "Multi-Agent Collaboration for Secure Code Generation with LLMs",
        "abstract": "This paper proposes a multi-agent framework...",
        "authors": [
          {
            "name": "John Smith",
            "authorId": "123456"
          }
        ],
        "year": 2023,
        "venue": "IEEE S&P (Oakland)",
        "citationCount": 45,
        "url": "https://...",
        "arxivId": "2301.12345"
      }
    ]
  }
}
```

### 健康检查

**URL**: `GET /api/v1/papers/health`

**响应**:
```json
{
  "status": "healthy",
  "service": "paper_search",
  "features": [
    "semantic_scholar_integration",
    "top_venue_filtering",
    "citation_ranking"
  ]
}
```

## 支持的顶会顶刊

系统优先返回以下顶会顶刊的论文：

### 安全领域 (A 类)
- CCS (ACM Conference on Computer and Communications Security)
- USENIX Security
- NDSS (Network and Distributed System Security)
- IEEE S&P (Oakland)

### 软件工程领域 (A 类)
- ICSE (International Conference on Software Engineering)
- FSE (Foundations of Software Engineering)
- ASE (Automated Software Engineering)
- ISSTA (International Symposium on Software Testing and Analysis)
- ESEC/FSE

### AI 领域 (A 类)
- NeurIPS
- ICML
- ICLR
- AAAI
- IJCAI

### 顶刊
- TOSE, TSE, TOSEM (软件工程)
- TDSC, TIFS (安全)

## 使用示例

### Python 示例

```python
import requests

# 搜索多智能体安全代码生成论文
response = requests.post(
    "http://localhost:8010/api/v1/papers/search",
    json={
        "query": "multi-agent secure code generation",
        "limit": 3,
        "yearFrom": 2020
    }
)

result = response.json()
for paper in result["data"]["papers"]:
    print(f"标题: {paper['title']}")
    print(f"会议: {paper['venue']} ({paper['year']})")
    print(f"引用数: {paper['citationCount']}")
    print()
```

### cURL 示例

```bash
curl -X POST "http://localhost:8010/api/v1/papers/search" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "基于多智能体的安全代码生成",
    "limit": 2
  }'
```

## 特性

1. **智能排序**: 优先返回顶会顶刊的论文，按引用数排序
2. **多语言支持**: 支持中英文查询
3. **灵活筛选**: 支持按会议、年份等维度筛选
4. **Fallback 机制**: 当外部 API 不可用时，返回内置的高质量论文
5. **完整信息**: 返回论文标题、作者、摘要、引用数、arXiv ID 等

## 测试

运行测试脚本：


## 注意事项

1. 外部 API 限流: Semantic Scholar API 有速率限制，频繁调用可能被限制
2. 网络要求: 需要能够访问 api.semanticscholar.org
3. Fallback 数据: 当外部 API 不可用时，系统使用内置的示例论文数据
